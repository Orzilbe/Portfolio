Ben-Gurion University Capstone Project

Unity Voice

Overview

A product-led development bridging voice-controlled technology and interactive systems. Recognized by Microsoft, this project was awarded Azure cloud credits for its innovative architecture.

Concept

The core goal was to make technology feel intuitive, not intimidating. By creating a voice-command interface, we allowed users to navigate complex software environments using natural language.

Technical Stack

Integrated speech-to-text APIs with a robust backend hosted on Microsoft Azure. Focused on real-time feedback loops and optimized architecture for low latency.
