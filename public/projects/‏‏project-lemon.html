Game Design & Development

Easy Peasy
Lemon Squeezy

Overview

A fast-paced, "one-minute" arcade experience developed in Unity. The project focuses on satisfying game feel, minimalist mechanics, and progressive difficulty scaling.

The Challenge

The goal was to create a game that is easy to learn but hard to master, all within a 60-second timeframe. This required precise tuning of physics, controls, and visual feedback.

Tech Stack

Developed using Unity and C#. Visual assets were designed to match a clean, vibrant aesthetic that emphasizes the "Lemon" theme.
